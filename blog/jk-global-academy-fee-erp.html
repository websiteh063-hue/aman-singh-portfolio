JK Global Academy Fee ERP: Admin Workflow and School Fee Management

This project is a full-stack school fee management system designed around real administrative workflows.

View Fee ERP Repository Back to Blog

Project goal

The ERP was created to help manage student records, fee structures, receipts, reports, and exports from one organized admin workflow.

Technical approach

The stack includes React, Tailwind, Node, Express, MongoDB, JWT authentication, PDF receipt generation, analytics, and Excel export support.

Result

The repository demonstrates a practical school ERP system with core operations that can support fee collection, reporting, and administration.
