# Aman Singh Resume Website

This is a static resume website for Aman Singh. It includes a responsive resume page, portfolio link, portfolio QR code, and a direct ATS-friendly A4 PDF download.

## Update Resume Content

Edit `resume-data.js` to update your name, title, contact details, education, skills, experience, interests, and portfolio link.

The portfolio URL is already set to `https://websiteh063-hue.github.io/aman-singh-portfolio/`.

## Open Locally

Open `index.html` in a browser.

## Make It Live On GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder.
3. In GitHub, go to `Settings` > `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select the `main` branch and `/root`, then save.
6. Your live resume link will appear on that Pages screen after GitHub finishes publishing.

## Files

- `index.html` - page structure
- `styles.css` - design and A4 print layout
- `script.js` - builds the page content
- `resume-data.js` - resume content you can update later
- `assets/aman-singh-profile.jpg` - profile photo
- `assets/portfolio-qr.png` - portfolio QR code
- `output/pdf/Aman-Singh-Resume-ATS.pdf` - downloadable ATS-friendly PDF
