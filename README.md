# Aman Singh Portfolio

SEO-friendly personal portfolio website for Aman Singh.

## Edit Before Publishing

- Replace `https://example.com/` in `index.html`, `robots.txt`, and `sitemap.xml` with your real domain.
- Replace `aman@example.com`, phone number, LinkedIn, and GitHub links in `index.html`.
- Update the project cards in the `Selected Work` section with your real work, client names, links, and results.
- Keep `assets/aman-singh.jpg` as your profile image or replace it with a new optimized image using the same filename.

Open `index.html` in a browser to preview the site.
