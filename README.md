# Aman Singh Portfolio

SEO-friendly personal portfolio website for Aman Singh.

## Edit Before Publishing

- Replace the GitHub Pages URL in `index.html`, `robots.txt`, and `sitemap.xml` if you connect a custom domain.
- Update LinkedIn and GitHub profile links in `index.html`.
- Add more project cards in the `All Work` section whenever you publish new work.
- Keep `assets/aman-singh.jpg` as your profile image or replace it with a new optimized image using the same filename.

Open `index.html` in a browser to preview the site.
